# KJ Snack — موقع المنيو

## التشغيل
```bash
npm install
npm run dev      # للتطوير: http://localhost:5173
npm run build    # نسخة النشر بمجلد dist/ (ترفعها على أي استضافة)
```

## وين بعدّل؟
| الملف | شو فيه |
|---|---|
| `src/data/menu.js` | كل الأصناف والأسعار والمكوّنات (الأسطر المعلّمة بـ `؟` بدها مراجعة) |
| `src/data/site.js` | الهاتف، الواتساب، العنوان، الدوام، السوشال، العملة، نص العرض الخاص |
| `src/styles/main.css` | الألوان والتصميم (المتغيّرات بأول الملف) |
| `reference/` | الصور الأصلية (المنيو، الشعار) |
